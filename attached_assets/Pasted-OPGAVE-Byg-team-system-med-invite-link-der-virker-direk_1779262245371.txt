DEL 2: INVITE-LINK FLOW
═══════════════════════════════════════

2.1 Admin opretter team:
- Klik "Team" i sidebar
- "Opret team" → indtast navn
- System genererer kode: 8 tegn, store bogstaver+tal
  Eksempel: NYBBAG26, REMAX01, HOME2026
- Viser invite-link: [origin]/join/[kode]

2.2 Admin kopierer link:
- [Kopier link] knap → kopierer til clipboard
- Admin sender link til kollega (Slack, mail, SMS)

2.3 Kollega klikker link:
- Åbner: https://nordichomebuild.repl.co/join/NYBBAG26
- Tjekker: Findes koden? → ja → viser teamnavn
- Viser: "Du er inviteret til Nybolig Bagsværd"
- To knapper:
  * [Jeg har allerede konto] → login → auto-tilsluttes
  * [Opret ny konto] → signup → auto-tilsluttes

2.4 Efter login/signup:
- System tjekker: invite kode i URL?
- Ja → kald API: POST /api/teams/join med kode
- Bruger tilsluttes team
- Redirect til dashboard
- Viser toast: "Du er nu medlem af Nybolig Bagsværd"

DEL 5: INVITE-LINK VIRKER HVER GANG
═══════════════════════════════════════

5.1 Kode generering:
function generateTeamCode() {
  const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';  // uden I, O, 0, 1
  let code = '';
  for (let i = 0; i < 8; i++) {
    code += chars.charAt(Math.floor(Math.random() * chars.length));
  }
  return code;  // fx "NYBBAG26"
}

5.2 Kode tjek:
- Unik i database (UNIQUE constraint)
- Case-insensitive tjek ved join
- Aldrig udløber (eller 30 dage hvis du vil)

═══════════════════════════════════════

ERSTAT alle separate tabeller med ÉN tabel:

CREATE TABLE generated_images (
  id SERIAL PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id),
  
  -- Hvis tilknyttet sag:
  case_id INTEGER REFERENCES bolig_cases(id) ON DELETE SET NULL,
  
  -- Hvis hurtig generering (uden sag):
  is_quick_generation BOOLEAN DEFAULT FALSE,
  quick_session_id TEXT,
  
  -- Billed-data:
  image_url TEXT NOT NULL,
  thumbnail_url TEXT,
  original_image_url TEXT,
  
  -- Valg (altid udfyldt):
  room_type TEXT NOT NULL,
  style TEXT NOT NULL,
  budget_tier INTEGER NOT NULL,
  
  -- Prompt brugt:
  prompt_text TEXT,
  
  -- Metadata:
  created_at TIMESTAMP DEFAULT NOW(),
  generation_time_ms INTEGER,
  created_date DATE DEFAULT CURRENT_DATE
);

INDEXES:
- INDEX ON (user_id, created_date)
- INDEX ON (user_id, case_id)
- INDEX ON (user_id, is_quick_generation)

3.2 Frontend mutation:

const generateImageMutation = useMutation({
  mutationFn: async (params: {
    caseId?: number;
    isQuick?: boolean;
    roomType: string;
    style: string;
    budgetTier: number;
    originalImageUrl?: string;
  }) => {
    const token = await auth.currentUser?.getIdToken();
    
    // 1. Hent prompt fra main versionens prompts
    const promptRes = await fetch(
      `/api/prompts?room=${params.roomType}&style=${params.style}&tier=${params.budgetTier}`,
      { headers: { Authorization: `Bearer ${token}` } }
    );
    const { prompt } = await promptRes.json();
    
    // 2. Send til Collov AI med prompt
    const res = await fetch("/api/generate", {
      method: "POST",
      headers: { 
        "Content-Type": "application/json",
        "Authorization": `Bearer ${token}`
      },
      body: JSON.stringify({ ...params, prompt }),
    });
    
    if (!res.ok) throw new Error("Generering fejlede");
    return res.json();
  },
  
  onSuccess: (data) => {
    // INVALIDÉR ALLE relevante queries
    queryClient.invalidateQueries({ queryKey: ["/api/stats/today"] });
    queryClient.invalidateQueries({ queryKey: ["/api/stats/total"] });
    queryClient.invalidateQueries({ queryKey: ["/api/bolig/cases"] });
    
    if (data.caseId) {
      queryClient.invalidateQueries({ 
        queryKey: ["/api/bolig/cases", data.caseId, "images"] 
      });
    }
    
    showToast({ title: "Billede genereret!" });
  },
});

DEL 4: DASHBOARD STATISTIK — ALT HÆNGER SAMMEN
═══════════════════════════════════════

4.1 API endpoints:

GET /api/stats/today
→ SELECT COUNT(*) FROM generated_images 
   WHERE user_id = $1 AND created_date = CURRENT_DATE

GET /api/stats/total
→ SELECT COUNT(*) FROM generated_images 
   WHERE user_id = $1

GET /api/stats/cases/active
→ SELECT COUNT(*) FROM bolig_cases 
   WHERE user_id = $1 AND status = 'active'

GET /api/stats/cases/sold
→ SELECT COUNT(*) FROM bolig_cases 
   WHERE user_id = $1 AND status = 'sold'

GET /api/stats/cases/total
→ SELECT COUNT(*) FROM bolig_cases 
   WHERE user_id = $1

GET /api/stats/avg-days
→ SELECT AVG(
     EXTRACT(DAY FROM NOW() - created_at)
   ) FROM bolig_cases 
   WHERE user_id = $1 AND status = 'active'

4.2 "Visuals i dag" nulstilles automatisk:
- created_date = CURRENT_DATE
- Ved midnat (00:00) er CURRENT_DATE ny dato
- COUNT bliver 0 automatisk — ingen cron job nødvendigt

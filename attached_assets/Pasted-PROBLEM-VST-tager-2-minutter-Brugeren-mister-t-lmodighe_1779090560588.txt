PROBLEM: VST tager ~2 minutter. Brugeren mister tålmodighed.

ANALYSE: To sekventielle kald + polling hvert 3. sekund.

LØSNING: Hurtigere polling + Collov pre-warm. Ingen ændring af VST workflow.

ÆNDRING 1: Reducer polling-interval fra 3000ms til 2000ms

// FØR:
const POLL_INTERVAL = 3000; // 3 sekunder

// EFTER:
const POLL_INTERVAL = 2000; // 2 sekunder

// Effekt: Opdager SUCCESS ~33% hurtigere
// Risiko: Højere load på Collov API — men indenfor rate limit (10/s)

ÆNDRING 2: Pre-warm Collov ved server start

// Tilføj i server startup (efter app.listen):

setTimeout(async () => {
  try {
    console.log('[Pre-warm] Warming Collov models...');
    
    // Send dummy VST kald der fejler hurtigt
    // Dette får Collov til at loade modeller i GPU RAM
    const form = new FormData();
    form.append('uploadUrl', 'https://example.com/dummy.jpg');
    
    await fetch('https://api.collov.ai/flair/enterpriseApi/vst/generateEmptyRoom', {
      method: 'POST',
      headers: { apiKey: process.env.COLOV_API_KEY },
      body: form
    });
    
    // Forventet: 400 eller 500 fejl — men modeller er nu loaded
    console.log('[Pre-warm] Models warmed');
  } catch (err) {
    // Forventet fejl — ignorer
    console.log('[Pre-warm] Done (expected error)');
  }
}, 10000); // 10 sekunder efter server start

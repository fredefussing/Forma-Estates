4. INTERAKTIVT FØR/EFTER-KOMPONENT
TypeScript
Copy
// components/BeforeAfterSlider.tsx
interface BeforeAfterSliderProps {
  slides: {
    before: string;
    after: string;
    label: string;
  }[];
  autoRotateInterval?: number; // default 5000ms
}

// Funktionalitet:
// - Viser først EFTER-billedet (det smukke resultat)
// - Bruger kan trække slider for at se FØR
// - Auto-rotate til næste slide hver 5 sekunder
// - Pause auto-rotate når bruger interagerer
// - Smooth transition mellem slides (0.5s ease-out)
// - Responsive: på mobil = swipe, på desktop = drag + click
Visual design:
Billeder i 16:9 aspect ratio
Slider-handle: 40px cirkel med --color-accent baggrund, hvid pil-ikon
Label i bunden af hvert billede (lille badge)
Subtle shadow på billed-container

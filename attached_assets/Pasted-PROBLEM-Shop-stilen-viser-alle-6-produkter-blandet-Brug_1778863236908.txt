2. GRUPPERINGS-LOGIK:

// Gruppér matches efter DB type
const grouped = products.reduce((acc, p) => {
  const dbType = p.tags?.type || 'other';
  if (!acc[dbType]) acc[dbType] = [];
  acc[dbType].push(p);
  return acc;
}, {} as Record<string, typeof products>);

// Vis i fast rækkefølge, kun grupper med produkter
{TYPE_ORDER.map(({ type, label, icon }) => {
  const items = grouped[type];
  if (!items || items.length === 0) return null;
  
  return (
    <div key={type} className="mb-4">
      <h4 className="text-sm font-semibold text-stone-700 flex items-center gap-2 mb-2">
        <span>{icon}</span>
        {label} ({items.length})
      </h4>
      <div className="grid grid-cols-3 gap-2">
        {items.slice(0, 3).map(product => (
          <ProductCard key={product.id} product={product} />
        ))}
      </div>
    </div>
  );
})}

3. RÆKKEFØLGE GARANTI:

Stole først → Borde → Reoler → Sofaer → Lamper → Planter

Hvis en type mangler i matches → vises IKKE (ingen tom række).
Hvis en type har 4+ matches → vis kun top 3.
Alle DB typer er engelsk (dining_chair, coffee_table, osv.).
Visning er dansk (Spisebordsstole, Sofaborde, osv.).

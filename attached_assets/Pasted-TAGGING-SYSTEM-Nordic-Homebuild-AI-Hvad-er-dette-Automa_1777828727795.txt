TAGGING SYSTEM — Nordic Homebuild AI
Hvad er dette?
Automatisk tagging af produkter med AI + "Shop dette look" feature.
Filer
Database
01_migration.sql — Tilføj tags kolonner og indexes
Backend
02_tagProducts.ts — Tagging engine (navn-parsing + GPT-4 Vision)
03_tag-top-products.ts — Batch script til at tagge 10.000 produkter
04_styleSearch.ts — Søgefunktion til "Shop dette look"
05_api_routes.ts — API endpoints
Frontend
06_ShopThisStyle.tsx — "Shop dette look" komponent
07_AIResultWithShopping.tsx — Integration med AI-billedet

Sådan fungerer det
Tagging
Parser produktnavn (gratis, hurtigt)
Hvis usikker (< 70% confidence), brug GPT-4 Vision på billede
Gemmer tags som JSONB i databasen
Søgning
Bruger vælger stil + rum + budget
System finder produkter med matchende tags
Sorterer efter confidence + match score
Viser 8 produkter i "Shop dette look"
Omkostninger
Table
Item	Pris
GPT-4o-mini per billede	~$0.005
10.000 produkter	~$50
Tid på Replit CPU	~6-8 timer
Forventninger
Table
Med tagging	Uden tagging
"Skandinavisk stue" viser skandinaviske produkter	Tilfældige produkter
Sofaer er faktisk sofaer	"Chair" matcher taburetter
Farver er i samme familie	Beige bliver brun
Stil er konsistent	Blander stilarter
Dette er IKKE præcis match — det er "konsistent stil".
Troubleshooting
Ingen produkter fundet
Tjek at tag_processed = TRUE for nogle produkter
Tjek at tags->>'style' matcher den valgte stil
Brug fallback søgning (bredere kriterier)
Langsom tagging
Replit har CPU limits
Sænk BATCH_SIZE til 50
Øg pause mellem kald til 10 sekunder
Vision fejler
Tjek OPENAI_API_KEY
Nogle billeder kan være utilgængelige (403)
Produktet markeres som processed alligevel

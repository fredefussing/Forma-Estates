DATABASe (4 tabeller — simpelt)

-- 1. KONTAKTER (mennesker)
CREATE TABLE crm_contacts (
  id TEXT PRIMARY KEY,           -- uuid
  email TEXT NOT NULL UNIQUE,
  name TEXT,
  company TEXT,                  -- "Nybolig Hellerup"
  phone TEXT,
  plan TEXT DEFAULT 'none',      -- none | starter | pro | business
  status TEXT DEFAULT 'lead',    -- lead | trial | active | churned
  engagement_score INTEGER DEFAULT 0,
  notes TEXT,                    -- fri tekst til dig
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  last_active_at DATETIME
);

-- 2. AKTIVITETER (alt der sker automatisk)
CREATE TABLE crm_activities (
  id TEXT PRIMARY KEY,
  contact_id TEXT REFERENCES crm_contacts(id),
  type TEXT NOT NULL,            -- visualization | download | video | login | upgrade
  description TEXT,              -- "Skandi stue, tier 2"
  metadata TEXT,                 -- JSON: {"room":"stue","tier":2}
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 3. INTERAKTIONER (noter du selv skriver)
CREATE TABLE crm_interactions (
  id TEXT PRIMARY KEY,
  contact_id TEXT REFERENCES crm_contacts(id),
  type TEXT DEFAULT 'note',      -- note | email | call | support
  content TEXT NOT NULL,         -- "Ringede — interesseret i Pro"
  created_by TEXT,               -- dit navn
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 4. ALERTS (ting der kræver din opmærksomhed)
CREATE TABLE crm_alerts (
  id TEXT PRIMARY KEY,
  contact_id TEXT REFERENCES crm_contacts(id),
  type TEXT NOT NULL,            -- churn_risk | upsell | no_activity | ticket
  message TEXT NOT NULL,
  is_read BOOLEAN DEFAULT FALSE,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

// /admin/crm/page.tsx
export default function CRMPage() {
  const [contacts, setContacts] = useState([]);
  const [filter, setFilter] = useState({ status: "", plan: "", search: "" });

  // Hent kontakter med filter
  const filtered = contacts.filter(c => {
    if (filter.status && c.status !== filter.status) return false;
    if (filter.plan && c.plan !== filter.plan) return false;
    if (filter.search && !c.name?.toLowerCase().includes(filter.search.toLowerCase())) return false;
    return true;
  });

  return (
    <div className="p-6 max-w-6xl mx-auto">
      {/* Header */}
      <div className="flex items-center justify-between mb-6">
        <h1 className="text-2xl font-bold">Kontakter ({contacts.length})</h1>
        <div className="flex gap-3">
          <input
            placeholder="Søg navn, email, virksomhed..."
            className="border rounded-lg px-4 py-2 w-64"
            onChange={e => setFilter(f => ({ ...f, search: e.target.value }))}
          />
          <select
            className="border rounded-lg px-3 py-2"
            onChange={e => setFilter(f => ({ ...f, status: e.target.value }))}
          >
            <option value="">Alle status</option>
            <option value="lead">Lead</option>
            <option value="trial">Trial</option>
            <option value="active">Aktiv</option>
            <option value="churned">Churned</option>
          </select>
          <select
            className="border rounded-lg px-3 py-2"
            onChange={e => setFilter(f => ({ ...f, plan: e.target.value }))}
          >
            <option value="">Alle planer</option>
            <option value="none">Ingen</option>
            <option value="starter">Starter</option>
            <option value="pro">Pro</option>
            <option value="business">Business</option>
          </select>
        </div>
      </div>

      {/* Tabel */}
      <div className="bg-white rounded-xl border shadow-sm">
        <table className="w-full">
          <thead className="bg-gray-50 text-sm text-gray-600">
            <tr>
              <th className="text-left px-4 py-3">Navn</th>
              <th className="text-left px-4 py-3">Virksomhed</th>
              <th className="text-left px-4 py-3">Plan</th>
              <th className="text-left px-4 py-3">Status</th>
              <th className="text-left px-4 py-3">Score</th>
              <th className="text-left px-4 py-3">Seneste aktivitet</th>
            </tr>
          </thead>
          <tbody>
            {filtered.map(contact => (
              <tr
                key={contact.id}
                className="border-t hover:bg-gray-50 cursor-pointer"
                onClick={() => router.push(`/admin/crm/${contact.id}`)}
              >
                <td className="px-4 py-3">
                  <div className="font-medium">{contact.name || contact.email}</div>
                  <div className="text-sm text-gray-500">{contact.email}</div>
                </td>
                <td className="px-4 py-3 text-gray-600">{contact.company || "-"}</td>
                <td className="px-4 py-3">
                  <PlanBadge plan={contact.plan} />
                </td>
                <td className="px-4 py-3">
                  <StatusBadge status={contact.status} />
                </td>
                <td className="px-4 py-3">
                  <ScoreBar score={contact.engagement_score} />
                </td>
                <td className="px-4 py-3 text-sm text-gray-500">
                  {contact.last_active_at
                    ? formatDate(contact.last_active_at)
                    : "Aldrig"}
                </td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>
    </div>
  );
}

// /admin/crm/[id]/page.tsx
export default function ContactDetail({ params }: { params: { id: string } }) {
  const [contact, setContact] = useState(null);
  const [activities, setActivities] = useState([]);
  const [interactions, setInteractions] = useState([]);
  const [newNote, setNewNote] = useState("");

  const handleAddNote = async () => {
    await fetch(`/api/crm/contacts/${params.id}/interactions`, {
      method: "POST",
      body: JSON.stringify({ type: "note", content: newNote }),
    });
    setNewNote("");
    // reload interactions
  };

  // Beregn aktivitets-tællere
  const counts = {
    visualizations: activities.filter(a => a.type === "visualization").length,
    videos: activities.filter(a => a.type === "video").length,
    logins: activities.filter(a => a.type === "login").length,
    downloads: activities.filter(a => a.type === "download").length,
  };

  return (
    <div className="p-6 max-w-4xl mx-auto">
      {/* Header */}
      <div className="flex items-start justify-between mb-6">
        <div>
          <h1 className="text-2xl font-bold">{contact?.name || contact?.email}</h1>
          <div className="flex items-center gap-3 mt-1 text-sm text-gray-500">
            {contact?.company && <span>🏢 {contact.company}</span>}
            <PlanBadge plan={contact?.plan} />
            <StatusBadge status={contact?.status} />
            <span>Medlem siden {formatDate(contact?.created_at)}</span>
          </div>
        </div>
        <div className="text-right">
          <div className="text-3xl font-bold">{contact?.engagement_score || 0}</div>
          <div className="text-sm text-gray-500">engagement score</div>
        </div>
      </div>

      {/* Aktivitets-kort */}
      <div className="grid grid-cols-4 gap-4 mb-6">
        <StatCard label="Billeder" value={counts.visualizations} icon="🖼️" />
        <StatCard label="Videoer" value={counts.videos} icon="🎬" />
        <StatCard label="Logins" value={counts.logins} icon="🔑" />
        <StatCard label="Downloads" value={counts.downloads} icon="⬇️" />
      </div>

      {/* Alerts */}
      {contact?.alerts?.length > 0 && (
        <div className="bg-yellow-50 border border-yellow-200 rounded-lg p-4 mb-6">
          <h3 className="font-medium mb-2">🔔 Alerts</h3>
          {contact.alerts.map(alert => (
            <div key={alert.id} className="text-sm text-yellow-800">
              {alert.type === "churn_risk" && "⚠️ "}
              {alert.type === "upsell" && "📈 "}
              {alert.message}
            </div>
          ))}
        </div>
      )}

      {/* Interaktioner / Notater */}
      <div className="bg-white border rounded-xl p-6 mb-6">
        <h3 className="font-medium mb-4">📝 Interaktioner</h3>

        {/* Tilføj notat */}
        <div className="flex gap-2 mb-4">
          <input
            value={newNote}
            onChange={e => setNewNote(e.target.value)}
            placeholder="Skriv notat, opfølgning, samtale..."
            className="flex-1 border rounded-lg px-4 py-2"
            onKeyDown={e => e.key === "Enter" && handleAddNote()}
          />
          <button
            onClick={handleAddNote}
            className="bg-blue-600 text-white px-4 py-2 rounded-lg hover:bg-blue-700"
          >
            Tilføj
          </button>
        </div>

        {/* Historik */}
        <div className="space-y-3">
          {[...interactions, ...activities]
            .sort((a, b) => new Date(b.created_at) - new Date(a.created_at))
            .map(item => (
              <div key={item.id} className="flex gap-3 text-sm">
                <span className="text-gray-400 w-20">
                  {formatDateShort(item.created_at)}
                </span>
                <span className="text-gray-500 w-24">
                  {item.type === "note" ? "📝 Notat" :
                   item.type === "visualization" ? "🖼️ Billede" :
                   item.type === "login" ? "🔑 Login" :
                   item.type === "email" ? "📧 Email" :
                   item.type}
                </span>
                <span>{item.content || item.description}</span>
              </div>
            ))}
        </div>
      </div>
    </div>
  );
}

PROMPT TIL REPLIT
plain
BYG SIMPLET CRM MVP — KUN TRACKING, INGEN AUTOMATION ENDNU:

=== DATABASe ===
Opret 4 tabeller:
- crm_contacts (id, email, name, company, phone, plan, status, engagement_score, notes, created_at, last_active_at)
- crm_activities (id, contact_id, type, description, metadata, created_at)
- crm_interactions (id, contact_id, type, content, created_by, created_at)
- crm_alerts (id, contact_id, type, message, is_read, created_at)

=== AUTO-LOG (tilføj eksisterende kode) ===
Når bruger:         → Log i crm_activities:
- logger ind        → type: "login"
- genererer billede → type: "visualization", description: "Skandi stue tier 2"
- downloader        → type: "download"
- opgraderer plan   → type: "upgrade"

Opdater også crm_contacts.last_active_at hver gang.

=== API ===
GET    /api/crm/contacts         → liste med filter (status, plan, search)
GET    /api/crm/contacts/:id     → detail med activities + interactions
PATCH  /api/crm/contacts/:id     → opdater plan, status, notes
POST   /api/crm/contacts/:id/interactions → tilføj notat
GET    /api/crm/alerts           → ulæste alerts

=== FRONTEND ===
Side: /admin/crm
  - Tabel: Navn | Virksomhed | Plan-badge | Status-badge | Score | Sidste aktivitet
  - Filter: dropdown status, dropdown plan, søgefelt
  - Klik på række → åbner detail

Side: /admin/crm/[id]
  - Header: Navn, virksomhed, plan, status, score
  - 4 kort: Billeder | Videoer | Logins | Downloads (tæl fra activities)
  - Alerts: gult kort hvis der er alerts
  - Interaktioner: liste kronologisk + input til nyt notat
  - Alt sammen én side, ingen tabs

=== UI STYLE ===
- Hvid baggrund, grå borders
- Status badges: lead=grå, trial=gul, active=grøn, churned=rød
- Plan badges: none=grå, starter=blå, pro=lilla, business=guld
- Score: 0-40=rød, 41-70=gul, 71-100=grøn
- Simpelt og rent — ingen avancerede grafer endnu

=== EKSISTERENDE BRUGERE ===
Når det deployes: Kør migration der opretter crm_contacts for ALLE eksisterende brugere i users-tabellen. Plan = deres nuværende plan, status = "active" hvis de har genereret noget, "lead" hvis ikke.

=== ENERGY-AWARE BEAT-SYNC (professionel reel-editing) ===

PROBLEM: Nuværende system bruger SAMME kliplængde for alle klip. 
Det lyder mekanisk. Moderne professionelle reels varierer pacing 
efter musikkens energi.

LØSNING: Analysér musikkens energi per beat-segment, og varier 
kliplængden derefter.

### STEP 2: Energy analysis per beat
For hvert beat-interval, mål RMS (loudness):

import numpy as np
import librosa

y, sr = librosa.load(musicPath, sr=None)
beat_frames = librosa.time_to_frames(beats, sr=sr, hop_length=512)

energies = []
for i in range(len(beat_frames)-1):
    segment = y[beat_frames[i]:beat_frames[i+1]]
    rms = np.sqrt(np.mean(segment**2))
    energies.append(rms)

avg_energy = np.mean(energies)
high_threshold = avg_energy * 1.25
low_threshold = avg_energy * 0.8

### STEP 3: Beat-plan med variabel kliplængde

 clips_plan = []
 i = 0
 while i < len(energies):
     # Bestem energi-niveau for dette segment
     if energies[i] > high_threshold:
         beats_per_clip = 1  # Høj energi = hurtig cut
     elif energies[i] < low_threshold:
         beats_per_clip = 4  # Lav energi = længere clip
     else:
         beats_per_clip = 2  # Medium = standard
 
     # Beregn varighed
     if i + beats_per_clip < len(beats):
         duration = beats[i + beats_per_clip] - beats[i]
     else:
         duration = beats[-1] - beats[i] if i < len(beats)-1 else 2.0
     
     # Clamp: boligvideoer skal altid vise rummet nok
     duration = max(duration, 1.2)   # MIN 1.2 sekunder
     duration = min(duration, 4.0)   # MAX 4.0 sekunder
     
     clips_plan.append({
         clipIndex: floor(i / avg_beats_per_clip),  # hvilket billede
         duration: duration,
         startBeat: i
     })
     
     i += beats_per_clip

### STEP 4: Trim AI-klip efter plan

For hvert clip i clips_plan:
   ffmpeg -i clip_{N}.mp4 -ss 0 -t {duration} -c copy clip_{N}_trimmed.mp4

VIKTIG: Tag altid fra starten af Kling-klippet (-ss 0), 
aldrig fra midten. Starten har den flotteste gimbal-bevegelse.

### STEP 5: Concat med hard-cut

ffmpeg -f concat -safe 0 -i clips.txt -c copy raw_video.mp4

INGEN transitions. INGEN crossfade. Hard-cut only.

### STEP 6: Musik overlay med fade

ffmpeg -i raw_video.mp4 -i music.mp3 -filter_complex \
"[1:a]afade=t=in:ss=0:d=2,afade=t=out:st={duration-3}:d=3,volume=0.35[a]" \
-map 0:v -map "[a]" -c:v copy -c:a aac -b:a 128k -shortest output.mp4

### MUSIK-TYPE PRESETS

Når bruger vælger musik-type, juster thresholds:

rolig:       low_threshold *= 1.1, high_threshold *= 1.3    → flere lange clips
moderne:     (standard thresholds)
uplifting:   low_threshold *= 0.8, high_threshold *= 0.9    → flere korte clips
spændt:      beats_per_clip progression 4→2→1→2→4 over tid

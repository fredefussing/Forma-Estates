## 🌐 2. HOST FLOW TRACKING (End-to-End)

Overvåg HELE kæden og identificer præcis hvor fejlen opstår:

GoDaddy (DNS) → Cloudflare (CDN/SSL) → Railway (Hosting) → Replit (Dev/Build) → GitHub (Repo) → App (Node/Express)
                    ↓
              Firebase (Auth) → PostgreSQL (DB) → Collov AI (Billeder) → fal.ai (Video)

### Checkpoints:
1. GoDaddy DNS - Domain formaestates.com resolver korrekt?
2. Cloudflare - CDN/SSL aktiv? Status 200?
3. Railway - App running? Health check OK?
4. GitHub - Repo tilgængelig? Sidste push succes?
5. Replit - Build succes? Dev miljø kører?
6. Firebase Auth - Auth service oppe? Login virker?
7. PostgreSQL - DB forbindelse? Query response < 2s?
8. Collov AI - API responsiv? Billede-generering virker?
9. fal.ai - API responsiv? Video-generering virker?
10. Sitemap/Robots - XML tilgængelig? Meta tags korrekte?

### Fejl-mail format:
Emne: 🚨 [CHECKPOINT NAVN] Fejl - Forma Estates
Indhold: 📍 Fejl lokation: [præcis checkpoint] | ⏰ Tidspunkt: [timestamp] | 🔴 Fejltype: [HTTP 500/Timeout/DNS Error] | 📝 Detaljer: [præcis fejlbesked] | Anbefalet handling: [step-by-step fix]

PROBLEM 1: cases.find() returnerer undefined på første render
Din kode:
- onSuccess: setPendingCase(newCase) → setModal(null) → openCase(newCase.id)
- openCase sætter: setSection("sag-detail") + setSelectedCaseId(newCase.id)
- React re-render: cases.find(x => x.id === selectedCaseId)
- MEN: cases kommer fra useQuery, og TanStack Query opdaterer IKKE med det samme
- Resultat: cases.find() = undefined → blank skærm / intet sker

FIX 1: Brug pendingCase som fallback korrekt
I din render-logic hvor du finder selectedCase:
const selectedCase = cases.find(x => x.id === selectedCaseId) ?? pendingCase;

ELLER endnu bedre: Brug newCase direkte fra mutation i stedet for at finde den igen:

  setSelectedCaseId(newCase.id);

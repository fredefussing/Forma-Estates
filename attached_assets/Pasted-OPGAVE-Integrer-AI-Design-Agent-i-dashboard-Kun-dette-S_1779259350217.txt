═══════════════════════════════════════
FUNKTIONALITET — KOPIER FRA MAIN VERSION
═══════════════════════════════════════

1. Upload billede:
- Træk-og-slip eller klik
- Vis thumbnail preview

2. Tekst-input:
- Textarea
- Max 500 tegn
- Placeholder med eksempler

3. Generer:
- Send til AI API (samme som main version)
- Loading-spinner
- Vis resultat

4. Resultat-handlinger:
- Download billede
- Gem til sag (dropdown: vælg aktiv sag)
- Prøv igen (samme billede + ny tekst)

═══════════════════════════════════════
TRACKING — GEM I generated_images
═══════════════════════════════════════

Når billede genereres, gem i generated_images tabel:

{
  user_id: [bruger id],
  case_id: null,           // null = ikke tilknyttet sag
  is_quick_generation: false,
  is_design_agent: true,   // ← NYT felt, markerer dette er fra AI Design Agent
  
  image_url: [url],
  thumbnail_url: [url],
  original_image_url: [uploadet billede],
  
  room_type: "Design Agent",  // ← eller brugerens valg hvis de angiver rum
  style: "Custom",            // ← custom da brugeren skriver egen prompt
  budget_tier: 0,             // ← 0 = ikke relevant for custom
  
  prompt_text: [brugerens tekst],  // ← gem den fulde prompt
  
  created_at: NOW(),
  created_date: CURRENT_DATE
}

TÆLLER med i:
- "Visuals i dag" ← JA (created_date = CURRENT_DATE)
- "Visuals i alt" ← JA (alle generated_images)
- "Seneste aktivitet" ← JA (vises som "Design Agent: [første 30 chars af prompt]")

TÆLLER IKKE med i:
- "Dine mest brugte valg" ← NEJ (style = "Custom", ikke en af de 8 stilarter)

═══════════════════════════════════════
FIX 1: SIKR AT INVALIDATE KØRER UANSET SECTION
═══════════════════════════════════════

Når brugeren genererer et billede, skifter section til sag-detail.
Dashboard unmountes. invalidateQueries mens unmounted = virker ikke.

I generate mutation onSuccess:

onSuccess: (data) => {
  // INVALIDÉR queries — dette virker selvom dashboard er unmounted
  queryClient.invalidateQueries({ queryKey: ["/api/bolig/activity"] });
  queryClient.invalidateQueries({ queryKey: ["/api/bolig/most-used"] });
  queryClient.invalidateQueries({ queryKey: ["/api/bolig/cases"] });
  
  // SÆT DATA DIREKTE i cache så det er klar når dashboard remountes
  queryClient.setQueryData(["/api/bolig/activity"], (old: any) => {
    if (!old) return [data];
    return [data, ...old].slice(0, 5);
  });
  
  // Vis toast
  showToast({ title: "Billede genereret" });
}

FIX 4: TJEK OM ACTIVITY HENTER FRA generated_images
═══════════════════════════════════════

I storage.getRecentActivity:

ERSTAT:
SELECT * FROM bolig_cases WHERE user_id = $1 ORDER BY created_at DESC

MED:
SELECT 
  gi.id,
  gi.room_type as roomType,
  gi.style,
  gi.budget_tier as budgetTier,
  gi.image_url as imageUrl,
  gi.created_at as createdAt,
  'generation' as type
FROM generated_images gi
WHERE gi.user_id = $1
ORDER BY gi.created_at DESC
LIMIT 5

Hvis du vil have SAG-oprettelser også:
UNION ALL
SELECT 
  bc.id,
  bc.address as roomType,
  null as style,
  null as budgetTier,
  null as imageUrl,
  bc.created_at as createdAt,
  'case' as type
FROM bolig_cases bc
WHERE bc.user_id = $1
ORDER BY createdAt DESC
LIMIT 5

FIX 5: TJEK OM MOST USED HENTER FRA ALLE generated_images
═══════════════════════════════════════

I storage.getMostUsed:

ERSTAT:
SELECT style, COUNT(*) as count 
FROM generated_images gi
JOIN bolig_cases bc ON gi.case_id = bc.id
WHERE bc.user_id = $1

MED:
SELECT style, COUNT(*) as count 
FROM generated_images
WHERE user_id = $1
GROUP BY style
ORDER BY count DESC
LIMIT 3

(VIGTIGT: Fjern JOIN med bolig_cases — det ekskluderer hurtig-genereringer!)

SAMME for rooms og tiers:
SELECT room_type, COUNT(*) as count FROM generated_images WHERE user_id = $1...
SELECT budget_tier, COUNT(*) as count FROM generated_images WHERE user_id = $1...

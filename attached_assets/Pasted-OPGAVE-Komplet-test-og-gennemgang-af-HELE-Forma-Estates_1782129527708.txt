═══════════════════════════════════════════════════════════════

□ Loader siden uden fejl?
□ Logo vises korrekt?

2. PRISER / PLANER (/#pricing)
═══════════════════════════════════════════════════════════════

□ 3 planer vises: Start, Pro, Business?
□ Månedlig/Årlig toggle virker?
□ Årlig viser "SPAR 20%" badge?
□ Priser korrekte: 2.999 / 5.999 / 11.999?
□ Årlige priser vises: 2.399 / 4.799 / 9.599?
□ Features liste korrekt pr. plan?
□ "MEST POPULÆR" badge på Pro?
□ "Vælg Start/Pro/Business" knapper virker?

□ Klik på "Vælg Pro" → hvad sker der?
  - HVIS IKKE LOGGET IND: Sendes til login? (SKAL ÆNDRES → gæst-checkout)
  - HVIS LOGGET IND: Stripe checkout åbner i SAMME vindue?
  - Loader/spinner vises mens checkout hentes?
  - Stripe URL returneres korrekt?

□ Efter betaling:
  - Redirect til /betalt?session_id=...
  - Henter session detaljer?
  - Plan aktiveres automatisk?
  - Redirect til /dashboard?
  - Plan vises som "Aktiv" med det samme?

3. BYG DIN PAKKE (/pakke eller /boligpotentiale)
═══════════════════════════════════════════════════════════════

□ 4 sliders vises: AI Visualisering, 3D Plantegning, Transformering Video, Bolig Showcase?
□ Slider max værdier: 200 / 60 / 60 / 60?
□ Pris opdaterer i realtid når slider trækkes?
□ Rabat-badge vises: "-28%", "-10%" osv.?
□ "Du sparer X kr. pr. stk." vises?
□ Samlet rabat beregnes korrekt?
□ Total-bar fast i bunden?
□ Original pris overstreget?
□ Endelig pris stor og tydelig?
□ "Vælg din pakke" knap kun aktiv når total > 0?

□ Klik på "Vælg din pakke":
  - HVIS IKKE LOGGET IND: Gæst-checkout tilladt? (SKAL VIRKE)
  - Stripe checkout åbner i SAMME vindue?
  - Spinner vises?
  - Stripe URL returneres?

□ Efter betaling:
  - Redirect til /betalt?session_id=...
  - Købte produkter gemt i database?
  - Kunde kan se "X/Y AI Visualiseringer tilbage"?
  - "Opret sag" knap tilgængelig?

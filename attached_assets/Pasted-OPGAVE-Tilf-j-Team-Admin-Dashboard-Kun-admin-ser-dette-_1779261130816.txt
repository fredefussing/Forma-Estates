ROLLER
═══════════════════════════════════════

users tabel — tilføj:
role: text DEFAULT 'user' CHECK (role IN ('user', 'admin'))
team_id: integer REFERENCES teams(id)

teams tabel:
id | name | owner_user_id | created_at

team_members tabel:
id | team_id | user_id | role | joined_at

Admin = bruger med role = 'admin' i team_members
Eller = bruger der oprettede teamet (owner_user_id)

Normal bruger = role = 'user'

═══════════════════════════════════════
DATA-BEREGNING
═══════════════════════════════════════

Medlemmer: COUNT team_members WHERE team_id = X

Visuals denne måned:
SELECT COUNT(*) FROM generated_images gi
JOIN users u ON gi.user_id = u.id
WHERE u.team_id = X
AND gi.created_at >= DATE_TRUNC('month', NOW())

Aktive sager:
SELECT COUNT(*) FROM bolig_cases bc
JOIN users u ON bc.user_id = u.id
WHERE u.team_id = X AND bc.status = 'active'

Team Performance per medlem:
SELECT 
  u.name,
  COUNT(gi.id) as visuals,
  COUNT(DISTINCT bc.id) as sager,
  AVG(gi.generation_time_ms) as avg_tid
FROM users u
LEFT JOIN generated_images gi ON u.id = gi.user_id 
  AND gi.created_at >= DATE_TRUNC('month', NOW())
LEFT JOIN bolig_cases bc ON u.id = bc.user_id AND bc.status = 'active'
WHERE u.team_id = X
GROUP BY u.id, u.name

Credits:
Gem i teams tabel: credits_remaining, credits_used_this_month

═══════════════════════════════════════
API ENDPOINTS
═══════════════════════════════════════

GET /api/team
→ Tjek om bruger er admin i team
→ Returner team data + medlemmer + stats

GET /api/team/members
→ Alle medlemmer i team med stats

POST /api/team/invite
→ Body: { email }
→ Send invite link
→ Opret invite token

DELETE /api/team/members/:id
→ Fjern medlem fra team
→ Kun admin

POST /api/team/credits/allocate
→ Body: { userId, amount }
→ Overfør credits til medlem
→ Kun admin

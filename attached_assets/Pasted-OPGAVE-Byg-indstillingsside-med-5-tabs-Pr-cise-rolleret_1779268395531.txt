ROLLERETTIGHEDER — HÅNDHÆVES I KODE
═══════════════════════════════════════

EJER (kun 1 per team):
- Alt: køb credits, slet team, ændr ejer, kick alle (admin + medlemmer), ændr roller
- Kan IKKE fjernes af andre
- Kan overføre ejerskab til admin

ADMIN:
- Inviter medlemmer, fjern MEDLEMMER
- Se forbrug, tildel credits (hvis ejer har givet adgang)
- Ændr medlem-roller
- KAN IKKE: købe credits, slette team, fjerne EJER, ændr ejerskab

MEDLEM:
- Bruge systemet, egne sager
- KAN IKKE: se Team-tab, invitere, fjerne, købe credits

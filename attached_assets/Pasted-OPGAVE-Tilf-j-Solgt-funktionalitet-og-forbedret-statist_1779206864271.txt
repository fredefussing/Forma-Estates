1.4 Database:

3.1 Data-beregning:
- visuals genereret i dag: COUNT WHERE created_at >= TODAY
- visuals genereret i alt: COUNT ALL generated_images
- sager aktive: COUNT WHERE status = "active"
- sager solgt: COUNT WHERE status = "sold"
- sager i alt: COUNT ALL bolig_cases
- gns. dage på marked: AVG(days_on_market) WHERE status = "active"

- Hover: subtle shadow

3.3 Placering:

- Rækkefølge: Header → Statistik → Aktive Sager → Solgte Sager → Hurtig-handlinger

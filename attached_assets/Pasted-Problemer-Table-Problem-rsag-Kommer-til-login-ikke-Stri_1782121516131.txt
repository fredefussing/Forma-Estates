3. Hent session og aktiver plan
JavaScript
// Frontend — /betalt side
useEffect(() => {
  const sessionId = new URLSearchParams(window.location.search).get('session_id');
  
  fetch(`/api/session-details/${sessionId}`)
    .then(r => r.json())
    .then(data => {
      if (data.status === 'paid') {
        // Aktiver plan i database
        fetch('/api/activate-plan', {
          method: 'POST',
          body: JSON.stringify({ 
            sessionId,
            email: data.customer_email,
            metadata: data.metadata
          })
        });
        
        // Redirect til dashboard
        window.location.href = '/dashboard';
      }
    });
}, []);

OPGAVE: Fix Stripe checkout flow — gæst-checkout + automatisk aktivering

PROBLEMER:
1. Bruger sendes til login i stedet for Stripe checkout
2. Checkout skal ske i SAMME vindue (ikke ny fane)
3. Efter betaling skal bruger sendes til dashboard med aktiv plan
4. Plan skal vises som aktiv med det samme

LØSNINGER:

1. FJERN login-krav fra checkout:
   - I pricing.tsx: fjern "if (!user) redirect til login"
   - I enterprise-calculator.tsx: fjern login-krav
   - Send customerEmail: user?.email || "" (tom string hvis gæst)

2. SAMME VINDUE checkout:
   - Brug window.location.href = url (IKKE window.open)
   - IKKE target="_blank" på nogen knapper

3. Success-side (/betalt):
   - Hent session_id fra URL
   - Kald /api/session-details/:sessionId
   - Hvis status === 'paid':
     * Gem ordre/abonnement i database
     * Hvis gæst: opret konto med email fra Stripe
     * Redirect til /dashboard

4. Backend endpoints:
   - POST /api/create-package-checkout: fjern login-krav
   - POST /api/create-subscription-checkout: fjern login-krav
   - POST /api/activate-plan: opret/aktiver bruger plan
   - GET /api/session-details/:sessionId: returner metadata

5. Dashboard:
   - Vis aktiv plan fra database
   - Vis forbrug: "Brugt X / Y AI Visualiseringer"
   - Vis "Opret sag" knap hvis de har købt produkter

STRIPE WEBHOOK (valgfrit men anbefalet):
   - Endpoint: POST /webhook
   - Events: checkout.session.completed
   - Opdater database når betaling bekræftes

BACKEND:

1. POST /api/calculate-package
   Input: { aiVisual, plan3d, transformVideo, showcase }
   For hvert produkt: find tier baseret på antal, beregn unitPrice, total, originalTotal, savings, discountPercent
   Output: {
     items: [{ name, quantity, unitPrice, originalUnitPrice, total, originalTotal, discountPercent }],
     originalTotal,
     grandTotal,
     totalSavings,
     totalDiscountPercent: (totalSavings / originalTotal) * 100
   }

2. POST /api/create-package-checkout
   Input: { aiVisual, plan3d, transformVideo, showcase, customerEmail }
   - Brug calculatePackage() til at beregne priser
   - Byg line_items med price_data (currency: dkk, unit_amount i øre)
   - Tilføj "Samlet rabat" som negativ line item (-totalSavings * 100 øre)
   - Opret Stripe Checkout session: mode: 'payment'
   - Returner { url: session.url }

FRONTEND (/pakke):

1. 4 ProductSlider komponenter:
   - Produktnavn + beskrivelse
   - Slider (range 0-200 for AI, 0-60 for andre)
   - Antal display
   - Pris/stk med rabat-badge (grøn)
   - "Du sparer X kr. pr. stk."

2. PriceSummary:
   - Original total (overstregnet)
   - Endelig total (stor, bold)
   - "Du sparer X kr. (Y% samlet rabat)" — grøn badge
   - "Vælg din pakke →" knap (kun aktiv når grandTotal > 0)

3. Realtime:
   - On slider change → debounce 200ms → fetch /api/calculate-package
   - Animer prisændringer
   - Opdater rabat-badges

Teknisk Analyse: Sådan bygger du Render.ai-style boligvideoer
Efter at have studeret dine 6 eksempelvideoer kan jeg konkludere følgende:
Hvad Render.ai FAKTISK gør (ikke AI)
Render.ai's videoer er ikke genereret af AI i traditionel forstand. De bruger simpel, men elegant billedmanipulation:
Table
Teknik	Beskrivelse	Kompleksitet
Ken Burns drift	Langsom zoom ind/ud + pan på statiske billeder	Lav
Crossfade transitions	Blød fade mellem to billeder (~1 sek)	Lav
Vertikal crop	Billederne croppes til 9:16 format	Lav
Musik-overlay	Baggrundsmusik med fade ind/ud	Lav
Watermark	"SAMPLE" tekst overlay	Lav
Pointen: Dette er 100% gørbart med FFmpeg på få sekunder — uden nogen AI-tjenester.
To approaches til dig
Approach A: FFmpeg (anbefalet — 90% af effekten til 1% af prisen)
Input: 15-20 boligbilleder
Process: FFmpeg sammensætter med zoompan + xfade + afade
Output: 30-60 sekunders MP4 i 1080x1920
Tid: ~5-10 sekunder per video
Kost: Gratis (server CPU)
Approach B: AI-genereret bevægelse (Kling 1.6 Pro)
Input: Samme 15-20 billeder
Process: Hvert billede → 3-sekunders AI-video med cinematisk bevægelse → sammensæt
Output: Ligner "levende" billeder med realistisk kamerabevægelse
Tid: ~2-3 minutter per video
Kost: ~$0.15-0.30 per billede
Min anbefaling: Start med Approach A. Det er det Render.ai reelt gør, og det ser allerede professionelt ud.

Copy
Byg en "Bolig Showcase Video Generator" feature til min Forma Estates platform:

## Funktionalitet
1. UPLOAD: Bruger uploader 15-25 boligbilleder (drag & drop, rækkefølge kan sorteres)
2. PREVIEW: Live preview af videoen før generering (canvas-baseret)
3. GENERER: System laver 30-60 sekunders vertikal video (9:16, 1080x1920, MP4)
4. DOWNLOAD: Video kan downloades eller deles direkte

## Teknisk spec (FFmpeg-approach)
- Backend: Node.js/Express med FFmpeg (ffmpeg-static npm package)
- Ken Burns: zoompan filter med random/specified zoom- og pan-retning per billede
  - zoom: zoom ind fra 1.0 til 1.15 over 4-5 sekunder
  - pan: langsom bevægelse (max 10% offset) i random retning
- Transitions: xfade filter med fade transition (~0.8 sek mellem hvert billede)
- Musik: Mulighed for at uploade/vælge baggrundsmusik, afade ind/ud
- Format: 9:16 vertikal, 1080x1920, 30fps, MP4 H.264
- Billeder: Auto-crop til center 9:16 ratio fra originalen

## API Endpoints
- POST /api/videos/upload-images — Upload billeder (multipart/form-data)
- POST /api/videos/generate — Start generering med config (rækkefølge, musik, transition type)
- GET /api/videos/:id/status — Check status (processing/complete/error)
- GET /api/videos/:id/download — Download færdig MP4
- DELETE /api/videos/:id — Slet video

## Frontend
- Drag-and-drop billedupload med sortering (react-beautiful-dnd)
- Konfigurationspanel: 
  - Valg af transition type (fade, slide, none)
  - Valg af musik (upload eller preset tracks)
  - Justering af varighed per billede (3-8 sek slider)
- Progress bar under generering
- Video player til preview af resultatet

## Filstruktur
- /uploads/images/ — Midlertidige billeder
- /uploads/videos/ — Færdige MP4'er
- /uploads/music/ — Baggrundsmusik

## FFmpeg command template
Generér noget i stil med:
ffmpeg -i img1.jpg -i img2.jpg ... -filter_complex 
"zoompan=z='min(zoom+0.0015,1.15)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=150:s=1080x1920,
[0][1]xfade=transition=fade:duration=0.8:offset=4.2[out1];..." 
-af "afade=t=in:ss=0:d=1,afade=t=out:st=28:d=2" output.mp4

## Krav
- Brug eksisterende tech stack fra Forma Estates
- Sørg for at cleanup midlertidige filer efter processing
- Max video størrelse: 50MB
- Queue system: max 1 generering ad gangen per bruger

           ↓
   "Spisestue → Scandinavian Warm"
        ○ ● ○  (3 prikker)
Tekniske krav:
To kolonner: 50% bredde hver
Gap mellem: 16px
Aspect ratio: 4:3 (eller 16:9 — test hvad der ser bedst ud)
Billeder: object-fit: cover så de fylder hele rammen
Skarpe, ikke blurry — original opløsning
2. SLIDESHOW-FUNKTION (auto-rotate)
Table
Tid	Hvad sker
0-4 sek	Slide 1 vises (Spisestue)
4-8 sek	Fade til slide 2 (Stue mørkegrøn → lys)
8-12 sek	Fade til slide 3 (Stue standard → premium)
12 sek	Loop tilbage til slide 1
Fade-specifikation:
Duration: 0.5 sekund
Easing: ease-out
Begge sæt billeder (før + efter) fader samtidig
3. INDICATOR-PRÆKER
plain
Copy
Slide 1 aktiv:  ● ○ ○  (første prik fyldt, andre tomme)
Slide 2 aktiv:  ○ ● ○  (anden prik fyldt)
Slide 3 aktiv:  ○ ○ ●  (tredje prik fyldt)
Størrelse: 8px diameter
Tom: rgba(0,0,0,0.2)
Fyldt: #1A1A1A (din primære farve)
Gap: 8px mellem prikker
Placering: Centreret under stil-label

6. INGEN BRUGER-INTERAKTION
Table
Dette skal IKKE være der	Begrundelse
Træk-slider	Bruger forvirres, billeder bliver halve
Swipe på mobil	Auto-rotate er nok
Pile-knapper	Unødvendigt clutter
Manuel navigation	Breaker flowet
Bruger skal bare kigge — ikke røre.

8. KODE-STRUKTUR (simpel)
TypeScript
Copy
// HeroSlideshow.tsx
const slides = [
  { before: "/images/before-1.jpg", after: "/images/after-1.jpg", label: "...", style: "..." },
  { before: "/images/before-2.jpg", after: "/images/after-2.jpg", label: "...", style: "..." },
  { before: "/images/before-3.jpg", after: "/images/after-3.jpg", label: "...", style: "..." }
];

const [currentSlide, setCurrentSlide] = useState(0);

useEffect(() => {
  const interval = setInterval(() => {
    setCurrentSlide((prev) => (prev + 1) % slides.length);
  }, 4000);
  return () => clearInterval(interval);
}, []);

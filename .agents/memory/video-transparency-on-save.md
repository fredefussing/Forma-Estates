---
name: Video transparency on save
description: AI-video previews stay clean; the saved delivery copy carries the transparency badge and metadata.
---

AI-generated transformation-video previews must not have a visible AI label burned into them. Create the marked delivery copy only when the user saves the video to a case, using the same AI-circle visual language and XMP/C2PA-compatible transparency metadata as saved AI images.

**Why:** Users need an unobstructed preview to judge the video, while the saved asset must carry the required disclosure in the correct Forma Estates treatment.

**How to apply:** Preserve a clean generated source for preview. Any new video flow that supports saving to a case should mark the saved copy rather than the preview source, and should pass the user's locale for the badge text.

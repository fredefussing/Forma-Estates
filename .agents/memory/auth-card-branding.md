---
name: Auth-card branding
description: Visual and placeholder conventions for public signup, login and password-reset cards.
---

Use the Forma gold wordmark on signup, login and password-reset cards. Small navigation and account-switch links use a darker accessible gold. The display-name placeholder is simply “John Doe” in every locale, without “F.eks.”, “E.g.” or other example prefixes.

**Why:** Dark wordmarks and muted links made the auth cards feel disconnected from the public brand, while example prefixes added unnecessary copy.

**How to apply:** Keep these treatments aligned across every auth state so switching between signup, login and reset does not change the visual language.

---
name: Examples room fidelity
description: Visual evidence and user-review constraints for room comparisons on the Examples page
---

Keep room comparisons on the Examples page grounded in verified before/after photographs of the same physical room, with varied room types rather than repeatedly showing the white, empty living room. The three existing style variants of that living room are not a suitable substitute for a new room: they only match that repeatedly used original.

**Why:** In the Acrobat review the user asked to replace the repeated room, include different room types, and make enlarged before/after images display in a consistent format. A previous pairing appeared correct in one asset directory but the running site served a different image with the same filename.

**How to apply:** Inspect the actually served image pair for matching architectural details before adding it. If showing several styles for one room, only present them together when real outputs all derive from the new source room. Keep whole-property and floorplan comparisons separate from room styling.

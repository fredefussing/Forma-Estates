name: Collov refinement fidelity
description: How to keep repeated Collov image adjustments sharp without changing user-requested content.
---

The unmodified, durable Collov provider result is the customer-facing preview. The first accepted provider result in a refinement chain is the stable clean master for every later adjustment; replay all accepted refinement requests against that master instead of feeding AI-generated descendants back into the model. Branding, the visible localized AI-edited badge, invisible watermarking, metadata, and any required re-encoding belong only on the final downloaded/exported copy. Every refinement must also receive the server-controlled precision refinement prompt, which locks the camera, unrequested details, and image fidelity while still permitting the requested change.

**Why:** The clean raw Collov image is the visual quality target. File-level lossless persistence prevents JPEG damage, but repeated AI-on-AI edits still progressively soften detail because the model reinterprets every pixel on each pass. Replaying the edit history from one stable master preserves cumulative intent without cumulative model generations. Compliance still belongs on the copy that leaves the editor.

**How to apply:** Persist provider bytes unchanged and durably before returning success. For the first adjustment, use the accepted AI result as the clean master. For later adjustments, traverse to that same root master and send prior requests plus the new request in chronological order, with the newest instruction winning conflicts. Apply final-download processing exactly once for JPG, PNG, and PDF, and fail visibly instead of falling back to a raw download. Final JPEG export must use quality 100 with 4:4:4 chroma. Keep raw masters in media reconciliation and orphan-cleanup inventories. Never use the original before-photo as the refinement master, because it does not contain the accepted staged design.

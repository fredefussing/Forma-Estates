---
name: Public page language continuity
description: When to expose language switching on Forma Estates marketing subpages.
---

Only present localized navigation and a language switcher on a marketing subpage when its entire visitor-facing body is translated. Keep the selected language consistent through page titles, media controls, calls to action and footer, not just the hero.

**Why:** A translated header above Danish-only product content makes a visitor think the whole page has changed language when it has not.

**How to apply:** When expanding localization to another product detail page, translate its full body and interactive labels for all supported languages before enabling its localized shell and switcher. Preserve media URLs, stable state identifiers and test IDs while translating display copy.
